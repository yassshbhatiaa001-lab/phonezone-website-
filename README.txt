PHONEZONE LANDING PAGE
======================

Open index.html in VS Code.

Recommended:
1. Open the folder in VS Code.
2. Install/use Live Server if available.
3. Right-click index.html -> Open with Live Server.

Folder structure:
PhoneZone_Landing_Page/
  index.html
  README.txt
  assets/
    images/
      showroom.jpg
      buy-phone.jpg
      sell-phone.jpg
      repair-phone.jpg

The main website images are stored locally, so the page does not depend on external image URLs.

BEFORE LAUNCH
-------------
Replace the demo shop information in index.html:
- 123 Main Street, Hackensack, NJ 07601
- (201) 555-0123
- info@phonezone.com
- Opening hours
- Demo statistics
- Demo reviews
- Google Maps location
- Social links

The enquiry form is prepared for Google Apps Script. Search in index.html for:
GOOGLE_SCRIPT_URL
and paste your deployed Apps Script Web App URL there after setting up the Google Sheet integration.
